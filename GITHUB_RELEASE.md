## Release title

AppStore++ 1.3.0 — Free release with optional donations

## Release notes

AppStore++ is free to use. This release adds a yellow Buy Me a Coffee button at the top right, with a gentle pulse that respects Reduce Motion. There is no Trial / Unlock screen or payment gate. Donations are optional and do not change feature access.

Saved Apple Account sign-in, platform selection, separate download/decryption folders, and guided local setup remain available.

Requires macOS 14 or later and Apple Silicon. Decryption additionally requires compatible macOS and matching local enrollment. Builds are ad-hoc signed and are not Developer ID signed or notarized.

Install using `AppStore++-1.3.0-AppleSilicon.pkg`, or unzip `AppStore++-AppleSilicon.zip` and move the application to Applications. Quit the running app before replacing it.

Support: https://buymeacoffee.com/100xtoday
